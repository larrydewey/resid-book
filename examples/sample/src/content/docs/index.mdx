## What remains is what matters

Everything above the body is the server: the hero, the actions, the
sidebar, the table of contents and the search.

<CardGrid>

```resid
Int schedule_bps(Int klass) {
    return if (klass <= 0) { 25 } else { if (klass == 1) { 50 } else { 100 } };
}

Int main() {
    comptime_print(schedule_bps(2));
    return 0;
}
```

```text title="Output"
100
```
